# AI_academy_CAPSTONE_finance_team
AI сургалтын хүрээнд манай групп компанийн санхүүгийн чиглэлээр ажилладаг оролцогчид нэг баг болон хамтарч, сургалтын төгсгөлийн Capstone Project-оо хэрэгжүүлж байна. Төслийн зорилго нь AI технологийг санхүүгийн бодит ажил, процесс болон өгөгдөлд ашиглах боломжийг судалж, группийн хэмжээнд хэрэгжүүлэх боломжтой практик шийдэл боловсруулах юм.
